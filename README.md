# Serenity Admin — Git Practice Playground

A simple admin dashboard for managing wellness center and esthetician/beauty practice clients. Built as a sandbox for learning git.

## Run it

Open `index.html` in your browser. No build step needed.

## Files

- `index.html` — page structure
- `styles.css` — styling and colors (see `:root` variables)
- `app.js` — client data and table/filter logic

## Practice ideas

- **Branching:** create `feature/add-client-form` and build the "Add Client" form
- **Small commits:** change the color palette in `styles.css`, commit; add a client in `app.js`, commit
- **Merge conflicts:** on two branches, edit the same line (e.g. a client's revenue or the `--primary` color), then merge
- **Rebase / amend:** tidy up a messy series of commits
- **Stash:** start a change, stash it, switch branches, pop it
- **Revert / reset:** undo a bad change
- **Tags:** tag a `v1.0` release
